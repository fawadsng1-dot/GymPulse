# GymPulse prototype

A responsive Next.js + React dashboard prototype using sample data.

## Requirements
- Node.js 20.9+ (recommended current LTS)
- npm

## Run locally (Windows PowerShell / macOS / Linux)
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Included
- Admin dashboard with KPI cards, attendance chart, membership mix and recent members
- Search/filter-like member search
- Admin / Member view switch
- Member activity and goal dashboard
- Add member / log workout modal (demo-only interactions)
- Responsive layout

## Prototype notes
All data is local mock data. Buttons and forms demonstrate UI interactions only. There is no real login, database, QR validation, notification delivery or payment integration yet.
